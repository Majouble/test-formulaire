Test d'écriture anonyme dans Grist

Détection du mode…

Test A — via le pont grist.docApi (mode Custom Widget)

Actif seulement si cette page est chargée dans un widget personnalisé Grist (donc dans une iframe sur une page Grist). Sinon la section reste grisée.

Test B — via l'API REST Grist en direct (sans passer par le pont widget)

Fonctionne dans n'importe quel onglet, même hors Grist. Renseignez l'hôte et l'identifiant du document (visibles dans l'URL du document Grist).

À observer

Ouvrez cette page une première fois en tant que widget personnalisé dans le document Grist de test (Test A), puis une seconde fois dans un onglet de navigation privée (donc déconnecté de Grist) en visitant l'URL où vous l'avez hébergée (Test B). Le vrai test d'anonymat, c'est la navigation privée — un onglet normal où vous êtes déjà connecté à Grist ne prouve rien.
