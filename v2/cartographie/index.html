Projet QGIS prêt à l'emploi : une page A4 par territoire (France, région académique, académie ou département : carte de repérage, légende, carte des points signalés, tableau), pour tout type de risque ou de menace, dans le scolaire comme dans le supérieur. Dézippez le dossier, ouvrez atlas.qgs dans QGIS (3.34 ou plus récent), puis Mise en page › « Atlas par académie » › Atlas › Exporter en PDF. Tous les réglages ci-dessous forment un profil, enregistré dans le document et partagé avec l'équipe.

Carte et modèle QGIS

Modèle QGIS :

Retouchez la mise en page dans QGIS (positions, couleurs, légende, couches ajoutées), enregistrez le projet en .qgs avec des chemins relatifs, puis déposez-le : il devient le modèle de ce profil. Le widget n'y change que les variables (titre, date, service, nombre de lignes), les colonnes du tableau si elles sont réglées ici, et les fonds IGN et le voile.

Colonnes à exporter

Filtres sur les valeurs

Seules les lignes dont la valeur est cochée sont exportées. Plusieurs filtres se cumulent.

Une entité par établissement

Les lignes d'un même établissement deviennent un seul point, avec nb_lignes (nombre de lignes). Pour chaque colonne date cochée : …_premier, …_dernier et …_nb_jours (jours distincts). Valeurs différentes d'une ligne à l'autre : les nombres sont additionnés, les textes listés, les cases cochées comptées. Indispensable pour calculer un taux : sinon un établissement signalé trois fois compte trois fois.

Ajouter d'autres établissements

La table de référence est une table du document qui liste tous les établissements avec leurs coordonnées, par exemple l'Annuaire de l'éducation importé dans Grist. Les établissements déjà présents dans l'export ne sont pas ajoutés deux fois. Chaque entité reçoit une colonne concerne : 1 pour les établissements de l'export, 0 pour ceux ajoutés. Sa moyenne sur une zone donne directement le taux d'établissements concernés.

Si le téléchargement est bloqué, copiez ce contenu dans un fichier texte avec la bonne extension.

Sur la table des signalements du socle, les coordonnées viennent de l'établissement (colonnes Latitude et Longitude du référentiel), avec les colonnes de l'établissement en attributs : rien à régler. Sur une autre table, ou pour forcer d'autres colonnes, réglez-les dans le panneau de droite du widget : soit Latitude et Longitude, soit une colonne Géométrie (WKT comme POINT(2.35 48.85) ou GeoJSON). Les colonnes cochées deviennent des attributs. Seules les lignes visibles dans le widget (filtres, liens) sont exportées.
